# Baseline Testing

Independent starting copy of the Barista Zero game, created 14 October 2026.

Open `index.html` to play. The app uses standalone HTML, CSS, JavaScript and local image assets; no build step is needed.

## Starting point

The six existing levels, coaching, timers, equipment animations and home screen are preserved. In-game branding still says Barista Zero until the new design is defined.

- `single-espresso.html`: single espresso
- `long-black.html`: long black
- `four-espresso-gbw.html`: four espressos with grind-to-weight
- `manual-dose.html`: single espresso with manual weighing
- `two-dose.html`: four espressos with dose adjustment
- `level-six.html`: final baseline challenge
- `completion.html`: completion screen

This folder has no publishing connection to the original game. Changes here do not update its live site.
